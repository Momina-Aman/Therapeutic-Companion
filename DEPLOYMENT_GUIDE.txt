# ============================================================================
# DETAILED WORKFLOW EXPLANATION
# ============================================================================

"""
WHAT HAPPENS WHEN YOU SEND A MESSAGE:

1. User Types in Chat
   "I'm feeling anxious about presentations"
   ↓

2. Streamlit Records Message
   Added to st.session_state.chat_history
   ↓

3. TherapistEngine.get_response() Called
   ├─ Retrieves top 5 therapeutic contexts from ChromaDB
   │  (most semantically similar to user message)
   │
   ├─ Loads user's journal (last 5 entries)
   │  From: ./user_data/{username}/journal.txt
   │
   ├─ Builds enriched prompt:
   │  "=== RETRIEVED CONTEXT ===
   │   [Top 3 docs about anxiety, presentations, etc.]
   │   === YOUR JOURNAL ===
   │   [Your recent reflections]
   │   === USER MESSAGE ===
   │   I'm feeling anxious..."
   │
   └─ Calls Gemini API with:
      - System prompt (therapeutic persona)
      - Conversation history (last 5 turns)
      - Enriched prompt with context
      ↓

4. Gemini Generates Response
   Uses retrieved context + journal + system prompt
   to generate empathetic, personalized response
   ↓

5. Response Displayed
   ├─ Shown in chat UI
   ├─ Added to session history
   └─ Ready for next turn of conversation

"""
